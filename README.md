# Customer Churn Prediction and Analysis

This project focuses on analyzing customer behavior and developing a machine learning model to predict customer churn. The objective is to identify the main factors associated with customer attrition and build a predictive solution that can help businesses detect customers who are at risk of leaving.


Dataset

The dataset used in this project was obtained from Kaggle.

Source: Kaggle Dataset

The dataset contains information about customers and their characteristics, including variables related to their services, account information, and customer behavior. The target variable indicates whether a customer has churned.

Note: The dataset is not included in this repository if it is subject to the original dataset's terms of use. Please refer to the Kaggle source above to download the original dataset.
